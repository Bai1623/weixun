# 拾梦项目交接文档

更新日期：2026-08-31
项目状态：PWA 第一版已完成，可继续进行本机 AI 接入与真机验收

## 1. 交接摘要

“拾梦”是一款本地优先的唯美梦境记录 PWA，支持文字草稿、本地录音、梦境档案、搜索筛选、程序生成封面、长图导出、完整备份恢复和可选 AI 网关。

当前版本不需要账号或云服务。没有配置 AI 地址时，除 AI 整理、录音转写和 AI 生图外，主要功能均可使用。

需要特别区分两类迁移内容：

- **项目源码**：通过 GitHub 分支迁移。
- **已记录的梦境、录音和图片**：保存在旧电脑浏览器的 IndexedDB 中，不会随 Git 提交上传，必须在旧电脑的“设置 → 备份与恢复”中导出 ZIP，再复制到新电脑恢复。

## 3. 新电脑启动步骤

### 3.1 获取代码

```bash
git clone git@github.com:Bai1623/weixun.git
cd weixun
git switch codex/preserve-root-dirty-20260822
cd 拾梦
```

如果新电脑还没有配置 GitHub SSH Key，可以使用 HTTPS 地址：

```bash
git clone https://github.com/Bai1623/weixun.git
```

### 3.2 准备环境

开发基线：

- Node.js：20.20.2
- npm：10.8.2

安装锁定依赖：

```bash
npm ci
```

第一次运行端到端测试前安装 Chromium：

```bash
npx playwright install chromium
```

### 3.3 本地运行

```bash
npm run dev -- --host 127.0.0.1 --port 5197
```

浏览器打开：

```text
http://127.0.0.1:5197/#/home
```

开发服务器端口不是代码约束；使用其他端口也可以，但浏览器存储按“协议 + 主机 + 端口”隔离。更换端口后看不到旧端口下的数据属于正常现象，可通过备份包迁移。

## 4. 用户数据迁移

在旧电脑执行：

1. 打开拾梦的“设置”页面。
2. 进入“备份与恢复”。
3. 点击“导出完整备份”，确认未加密提示。
4. 保存生成的 `拾梦备份-YYYY-MM-DD.zip`，并复制到新电脑。

在新电脑执行：

1. 启动拾梦并完成首次说明。
2. 打开“设置 → 备份与恢复”。
3. 点击“选择备份恢复”，选择 ZIP 文件。
4. 检查预览中的梦境和媒体数量，再确认恢复。

恢复采用合并策略，不会先清空新电脑的数据；完全相同的记录会跳过，ID 相同但内容不同的记录会生成恢复副本。

> 备份包未加密，包含梦境原文、录音和 AI 图片。不要上传到公共仓库或公开网盘。

## 5. 已实现功能

- 首次启动隐私与备份说明。

- 浏览器本地录音、暂停、继续、试听和持久化保存。

- 标题、正文、摘要和标签搜索，以及情绪、清晰度、清醒梦、收藏筛选。
- 收藏、编辑、可撤销删除。
- 单篇梦境长图预览与导出。
- 包含文字和媒体的 ZIP 完整备份、预览和合并恢复。
- PWA 安装提示、离线应用壳、持久存储申请和安全更新提示。
- 可配置的 AI 网关客户端、逐次发送确认和结果应用流程。

## 7. 技术架构

### 7.1 技术栈

- Vue 3 + TypeScript + Vite
- Vue Router（Hash Router）
- Pinia
- IndexedDB + `idb`
- `MediaRecorder` / Blob
- Canvas 2D
- `fflate`
- `vite-plugin-pwa` / Workbox
- Vitest + Vue Test Utils + Playwright

### 7.2 主要目录

| 路径                     | 职责                                           |
| ------------------------ | ---------------------------------------------- |
| `src/core/persistence/`  | IndexedDB schema、数据库打开和存储错误映射     |
| `src/features/dreams/`   | 梦境模型、仓储、Store、编辑器、搜索和离线封面  |
| `src/features/media/`    | 录音控制、媒体仓储和本地播放器                 |
| `src/features/backup/`   | 版本化 ZIP 备份、校验、预览和恢复              |
| `src/features/export/`   | 梦境长图排版和导出                             |
| `src/features/ai/`       | AI 契约、HTTP 适配器、用户确认和调用状态       |
| `src/features/settings/` | 本地设置模型、仓储和 Store                     |
| `src/pages/`             | 首次说明、梦河、记录、详情、档案和设置页面     |
| `src/pwa/`               | 安装提示、Service Worker、存储持久化和更新安全 |
| `e2e/`                   | 核心流程、备份、离线和 AI 边界端到端测试       |

### 7.3 页面路由

应用使用 Hash Router，方便部署到静态托管：

- `#/onboarding`：首次说明
- `#/home`：梦境长河
- `#/record/:id?`：新建或编辑梦境
- `#/dream/:id`：梦境详情
- `#/archive`：梦境档案
- `#/settings`：设置、安装、AI 地址、备份恢复

### 7.4 数据边界

IndexedDB 数据库名称为 `shimeng`，版本为 1，包含三个对象仓库：

- `dreams`：草稿和正式梦境。
- `media`：录音和 AI 图片 Blob。
- `settings`：首次说明、动态偏好、AI 地址和最后备份时间。

Pinia 只负责界面编排，不是长期数据真源。离线封面由固定种子即时渲染，不长期保存 Blob。Service Worker 只缓存应用壳和静态资源，不缓存梦境正文、录音、备份或 AI 请求。

核心模型定义：

- `src/features/dreams/model/dream.ts`
- `src/features/media/model/media.ts`
- `src/features/settings/model/settings.ts`

修改模型或数据库 schema 时必须同时设计版本迁移，不能直接改变现有字段后仍保持数据库版本 1。

## 8. AI 网关契约

设置页填写的是受信任的服务端基础地址，不是 OpenAI API Key。远程地址必须使用 HTTPS；本地开发允许 `http://localhost`、`http://127.0.0.1` 和 `http://[::1]`。

前端会调用以下接口：

### 8.1 整理梦境

```http
POST {endpoint}/organize
Content-Type: application/json
```

请求：

```json
{
  "rawText": "梦境原文",
  "metadata": {
    "dreamedAt": "2026-08-31",
    "mood": "mysterious",
    "clarity": 3,
    "lucid": false,
    "tags": ["湖面", "门"]
  }
}
```

响应：

```json
{
  "title": "雾中的门",
  "summary": "我沿着湖面走向一扇门。",
  "mood": "mysterious",
  "keywords": ["湖面", "雾", "门"]
}
```

超时：45 秒。`mood` 必须是 `calm`、`joyful`、`mysterious`、`sad`、`anxious`、`fearful`、`surreal` 或 `neutral`。

### 8.2 录音转写

```http
POST {endpoint}/transcribe
Content-Type: multipart/form-data
```

表单字段名为 `audio`，响应为：

```json
{
  "transcript": "转写后的文字"
}
```

超时：120 秒。

### 8.3 梦境生图

```http
POST {endpoint}/image
Content-Type: application/json
```

请求：

```json
{
  "summary": "我沿着湖面走向一扇门。",
  "mood": "mysterious",
  "keywords": ["湖面", "雾", "门"]
}
```

响应必须直接返回非空图片二进制，并带 `image/*` Content-Type。超时：120 秒。

如果网关与页面不是同源，服务端需要正确配置 CORS。密钥只能保存在服务端环境变量中，不能写入 Vue 源码、浏览器设置或构建产物。

相关实现：

- `src/features/ai/services/DreamAiGateway.ts`
- `src/features/ai/services/HttpDreamAiGateway.ts`
- `src/features/ai/composables/useDreamAi.ts`

## 9. 建议的下一阶段

优先级建议：

1. 接入本机文字整理网关，例如本地 Ollama；先实现 `/organize`。
2. 接入本地 Whisper 转写；实现 `/transcribe` 并用真实浏览器录音验证 MIME 类型兼容性。
3. 完成 Android Chrome 与 iPhone Safari 真机验收，记录设备和系统版本。
4. 评估本地生图的机器性能后再实现 `/image`，不要让生图阻塞文字记录主流程。
5. 确认部署域名和备份策略，再决定是否增加云同步或原生应用包装。

本机网关应保持现有三个前端接口不变，避免让 UI 直接依赖 Ollama、Whisper 或任一模型供应商的私有格式。
