# 拾梦 PWA 第一版设计

日期：2026-08-25
状态：已由用户确认，待按实施计划开发

## 背景

用户希望制作一个可以长期记录个人梦境的唯美应用。产品参考小红书“梦境碎片 / vibe coding”作品的朦胧氛围，也参考 DreamNorth、DreamLog、OpenGnothia 和 LucidSourceKit 的快速记录、本地优先、AI 整理与梦境可视化能力，但不直接复制其中任何产品。

第一版名称为“拾梦”，形态为可安装的移动端 PWA，同时支持 Android Chrome 和 iPhone Safari。产品不要求注册账号，梦境、录音、封面和 AI 结果默认保存在当前设备。没有配置 AI 服务时，除在线转写、整理和生图外的全部核心流程仍须完整可用。

## 产品目标

- 让用户醒来后可以在尽量少的操作内用文字或录音留住梦境。
- 用稳定、克制的视觉语言把梦境记录变成值得回看的个人档案。
- 自动生成无需联网的梦境氛围封面。
- 为可选的 AI 录音转写、内容整理和梦境生图提供明确、安全的接入边界。
- 默认本地保存，支持完整备份、恢复和单篇梦境长图导出。
- 作为 PWA 安装到手机桌面，并在离线状态下完成记录、浏览和管理。

## 非目标

- 第一版不提供账号、云同步、社交社区、好友关系或公开作品广场。
- 第一版不提供付费订阅、广告或应用商店原生上架。
- 第一版不做权威解梦、心理诊断、吉凶判断或医疗建议。
- 第一版不实现四位数应用锁或本地数据库加密。
- 第一版不内置任何用户不可控的 AI API Key，也不把密钥写入前端构建产物。
- 第一版不承诺浏览器厂商永久保留站点数据；通过持久化存储申请和备份提醒降低数据丢失风险。

## 已确认的产品决策

1. 应用名称为“拾梦”。
2. 第一版是 Android 与 iPhone 均可安装的 PWA。
3. 梦境数据只保存在本机，不注册账号，不做云同步。
4. 支持文字输入、本地录音和可选 AI 转写。
5. AI 能力包括标题、摘要、情绪、关键词整理和梦境生图，不做权威解梦。
6. 每条梦境始终拥有离线生成的氛围封面；用户主动操作时可以替换为 AI 生图结果。
7. 梦境字段包括日期、正文、录音、心情、清晰度、是否清醒梦、标签和收藏。
8. 视觉采用雾白水面、暮蓝淡粉、微光星尘和胶片颗粒，首页表现为缓慢漂浮的梦境长河。
9. 支持完整备份包导出与恢复，以及单条梦境长图导出。
10. 第一版本地交付默认没有真实 AI Key；离线功能完整可用，在线功能通过可配置服务端端点启用。

## 技术路线

### 选择

使用 Vue 3、TypeScript 和 Vite 构建单页 PWA。使用 Vue Router 管理页面，Pinia 管理界面会话状态，IndexedDB 保存长期数据和二进制媒体，Service Worker 缓存应用壳与静态资源。

选择这条路线的原因：

- 工作区已有 Vue、Vite、Pinia 项目，可以沿用已有组织方式和测试习惯。
- 相比原生 HTML/TypeScript，页面、录音、导入导出和异步 AI 状态更容易保持清晰边界。
- 相比云端全栈，静态 PWA 更符合本地隐私、低成本和第一版快速交付目标。

## 信息架构

### 首次启动

首次打开显示简短引导：

1. 说明梦境默认只保存在当前设备。
2. 说明浏览器数据可能因清理站点数据而丢失，建议定期备份。
3. 说明 AI 功能只有在用户主动触发且服务已配置时才会向外发送当前梦境或录音。
4. 进入首页后不再强制展示引导，可在设置中重新查看。

首次启动不要求注册、填写个人资料或配置 AI。

### 首页：梦境长河

- 顶部展示“拾梦”、当天日期和一句克制的引导语。
- 主操作为“记录昨夜的梦”。
- 最近梦境以纵向错落的卡片呈现，卡片使用对应的离线或 AI 封面。
- 卡片显示标题、日期、主要情绪、摘要片段和收藏状态。
- 页面背景具有低频水面、雾气和星尘动效；在系统开启减少动态效果时停用位移动画。
- 空状态展示一张示例氛围画和明确的首次记录入口，不伪造用户数据。

### 记录页

- 默认聚焦正文输入区，不要求先填写标题。
- 支持开始、暂停、继续、完成、试听和删除本地录音。
- 支持选择梦境日期、心情、清晰度（1–5）、是否清醒梦、标签和收藏。
- 正文和元数据在输入过程中自动保存为草稿。
- 用户明确点击“保存梦境”后转为正式记录；退出未保存页面时草稿仍可恢复。
- 保存时立即生成离线封面，不等待网络或 AI。

### 梦境详情页

- 以大幅封面、标题、日期和情绪作为视觉焦点。
- 展示正文、摘要、关键词、梦境元数据和本地录音播放器。
- 提供编辑、收藏、删除和导出长图操作。
- AI 服务未配置时，AI 操作显示“尚未配置”，并提供前往设置的说明，不显示虚假的加载或成功状态。
- AI 服务已配置时，提供“整理梦境”“转写录音”“把梦画出来”。每次调用前明确提示将发送的内容，并由用户确认。
- AI 整理结果不会覆盖原始正文；用户可以保留、重新生成或清除整理结果。
- AI 生图完成后保存为本地媒体，并允许恢复到离线封面。

### 梦境档案页

- 按月份分组展示全部正式记录。
- 搜索范围包括标题、原始正文、摘要和标签。
- 支持按情绪、清晰度、清醒梦和收藏筛选。
- 搜索和筛选完全在本机执行。

### 设置与备份页

- 展示 PWA 安装提示和当前安装状态。
- 展示梦境数量、录音数量、图片数量及估算本地空间占用。
- 支持导出完整备份包、预览导入内容并恢复。
- 展示 AI 服务端点是否可用，但不在页面中接收或保存服务端密钥。
- 支持重新查看隐私说明和首次启动引导。

## 视觉与交互

### 视觉语言

- 主色：暮蓝、雾灰、月白和低饱和淡粉。
- 强调色随梦境情绪变化，但保持低饱和，避免大面积霓虹色。
- 字体以系统中文字体为主，标题可使用带轻微文学感的衬线备用字体栈，不依赖在线字体才能正常显示。
- 卡片使用半透明雾面层、柔和边缘和少量颗粒，不使用高亮玻璃拟态堆叠。
- 图标使用统一线性 SVG 风格，应用图标使用“月牙、门与水纹”的简化组合。

### 离线封面生成

离线封面由 Canvas 2D 生成，输入为梦境 ID、梦境时间、心情、清晰度和标签。生成器使用固定种子，因此相同记录在相同版本下得到相同画面。

画面分层：

1. 情绪决定的天空与水面渐变。
2. 清晰度决定的雾化和对比度。
3. 时间决定的月光、晨光或夜色。
4. 标签哈希决定的远景轮廓、微光位置和星尘分布。
5. 统一的水纹与低强度胶片颗粒。

生成器必须在没有网络、没有图片素材和没有 AI 服务时工作。离线封面既用于卡片，也可渲染为导出长图的背景。

### 移动端约束

- 以 360px 宽的竖屏作为最小主要布局，不出现横向滚动。
- 主要触控目标不小于 44×44 CSS 像素。
- 适配 iPhone 安全区域和 Android 浏览器底部工具栏变化。
- 键盘弹出时记录页主要输入和保存操作仍可访问。
- 动效不得阻塞滚动、输入或低端设备上的核心操作。

## 数据模型

### DreamRecord

```text
id: string
schemaVersion: 1
status: draft | saved
createdAt: ISO timestamp
updatedAt: ISO timestamp
dreamedAt: ISO date
rawText: string
title: string | null
summary: string | null
mood: calm | joyful | mysterious | sad | anxious | fearful | surreal | neutral
clarity: 1 | 2 | 3 | 4 | 5
lucid: boolean
tags: string[]
favorite: boolean
audioAssetIds: string[]
coverSeed: string
coverPalette: string
aiImageAssetId: string | null
aiKeywords: string[]
aiUpdatedAt: ISO timestamp | null
```

`rawText` 永远是用户原文。`title`、`summary` 和 `aiKeywords` 可以由 AI 生成，也可以由用户修改。AI 再次整理时先生成候选结果，用户确认后才替换现有整理字段。

### MediaAsset

```text
id: string
dreamId: string
kind: audio | ai-image
mimeType: string
size: number
createdAt: ISO timestamp
blob: Blob
```

离线封面按种子实时生成，不作为 Blob 长期保存。录音和 AI 图片使用独立媒体表，避免把二进制数据混入梦境 JSON。

### AppSettings

```text
schemaVersion: 1
onboardingCompleted: boolean
reducedMotionOverride: system | reduce | allow
aiEndpoint: string | null
lastBackupAt: ISO timestamp | null
```

设置只保存非敏感配置。AI API Key 不属于前端数据模型。

## 存储边界

- 梦境、设置和媒体使用 IndexedDB。
- Pinia 只保存当前页面状态、筛选条件、草稿编辑状态和短生命周期对象 URL，不作为长期数据真源。
- Service Worker 只缓存应用壳和静态资源，不缓存 AI 请求、梦境正文或导出包。
- 应用在浏览器支持时请求持久化存储，并显示请求结果；请求成功也不替代备份。
- 删除梦境时同时删除其录音和 AI 图片。界面提供短暂撤销窗口，撤销窗口结束后执行持久化删除。

## 录音流程

1. 用户主动点击录音并授予麦克风权限。
2. 应用根据浏览器能力选择可用的 MediaRecorder MIME 类型，不固定依赖单一编码。
3. 暂停或完成后生成本地 Blob，并写入媒体表。
4. 页面通过临时对象 URL 试听；离开页面时释放对象 URL。
5. 浏览器不支持录音或权限被拒绝时，文字记录仍可使用，并给出明确说明。
6. AI 转写只在服务已配置、用户主动选择录音并确认发送后进行；转写结果作为候选文本，不自动覆盖原文。

## AI 接入边界

前端依赖稳定的 `DreamAiGateway` 接口，而不直接依赖某一家模型：

```text
organizeDream(rawText, metadata) -> title, summary, mood, keywords
transcribeAudio(audioBlob) -> transcript
generateDreamImage(summary, mood, keywords) -> imageBlob
```

第一版本地交付包含：

- AI 接口定义和调用状态管理。
- 可配置的同源或允许跨域的服务端端点。
- 未配置、需要确认、处理中、成功、失败和可重试状态。
- 使用模拟网关的自动化测试。

第一版本地交付不包含真实密钥。真实服务启用时，密钥只能存在于服务端环境变量；浏览器向受控端点发送请求，服务端再调用模型提供商。AI 图片和结构化结果返回后立即写入本地存储，服务端不承担长期梦境存储。

发送边界：

- 整理梦境发送当前梦境原文和用户已选择的非敏感元数据。
- 转写只发送用户选中的录音。
- 生图优先发送用户确认后的摘要、情绪和关键词，不发送录音。
- 每次调用前展示将发送的数据类型；用户取消后不产生网络请求。

## 备份、恢复与长图导出

### 完整备份

完整备份为带版本清单的压缩包：

```text
manifest.json
dreams.json
media/{assetId}.{ext}
```

`manifest.json` 记录格式版本、导出时间、梦境数量和媒体数量。第一版备份包不加密，导出前明确提示用户妥善保存。

### 恢复

1. 读取并校验清单、数据版本、记录结构、媒体类型和实际文件。
2. 展示待导入梦境、录音和图片数量。
3. 用户确认后执行合并，不先清空本地数据。
4. 完全相同的 ID 和内容跳过。
5. ID 相同但内容不同的记录作为“恢复副本”生成新 ID，避免静默覆盖。
6. 任一关键校验失败时停止导入，并保持现有数据不变。

### 单篇长图

长图包含离线或 AI 封面、标题、日期、正文或摘要、情绪和标签。导出前提供预览；录音和隐私说明不进入长图。正文过长时生成多页图片或提示仅导出摘要，不能通过缩小到不可读字号强行塞入一张图。

## PWA 与离线策略

- Manifest 提供名称“拾梦”、主题色、独立窗口模式和必要尺寸图标。
- Service Worker 预缓存应用壳、图标和本地静态资源。
- 页面导航使用适合静态托管的回退策略，刷新子页面不会返回 404。
- 离线时隐藏或禁用需要网络的 AI 操作，但不影响记录、播放、搜索、导出和恢复。
- 新版本可用时提示用户刷新，不在用户正在编辑或录音时强制替换页面。

## 状态与错误处理

- 草稿：每次关键字段变化后防抖保存；保存失败时保留页面内容并显示持续警告。
- 麦克风：权限拒绝、设备占用、不支持 MediaRecorder 和编码失败分别给出可行动说明。
- 存储：写入前后捕获配额错误；失败时不把记录误标为已保存，并引导删除大录音或导出备份。
- AI：请求设置超时并允许重试；失败不改变原文、已有摘要或已有图片。
- 删除：显示撤销入口，关联媒体只有在撤销期结束后删除。
- 导入：先验证、后写入；写入过程在单一事务或可回滚步骤中完成。
- 页面更新：存在未保存输入或进行中录音时延迟应用新版本。

## 第一版实施边界

第一版包含五个可独立验收的部分：

1. PWA 应用壳、视觉系统和安装能力。
2. 本地梦境与媒体存储、记录、详情、档案和搜索。
3. 本地录音、离线封面和梦境长图。
4. 完整备份、恢复和存储状态提示。
5. 可插拔 AI 网关、明确的隐私确认和模拟测试。

真实 AI 服务端部署和密钥配置属于第一版之后的启用步骤，不阻塞本地第一版验收。启用时不改变本地数据模型和页面主流程。

## 验收标准

- 用户无需登录或联网即可安装、打开并使用拾梦核心功能。
- 用户可以创建、编辑、收藏、搜索、筛选和删除梦境。
- 正文输入会自动保存草稿，意外刷新后可恢复。
- 支持的浏览器中可以录音、试听，并在重启应用后继续播放。
- 每条正式梦境都会立即获得稳定、唯美的离线封面。
- 首页、详情和档案在 360px 竖屏及 iPhone 安全区域内可正常使用。
- 用户可以导出完整备份、无损恢复梦境与媒体，并安全处理冲突。
- 用户可以把单条梦境导出为可读的唯美长图。
- AI 未配置时，应用不会伪造结果或影响离线功能。
- AI 已配置时，每次外发前都有明确确认，失败不覆盖原始内容。
- 自动化测试覆盖本地核心流程、备份恢复和 AI 状态边界。
- 项目完全位于“拾梦”独立目录，不修改工作区内其他项目。
